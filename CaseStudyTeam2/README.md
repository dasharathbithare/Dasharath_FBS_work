🏦 Bank Management System

A simple console based *Bank Management System* developed using *Core Java*.

 📌 About the Project

This project is designed to manage basic banking operations such as creating and managing accounts, performing transactions, searching accounts, closing accounts, and generating an End of Day Report.

The system includes

💰 Savings Account  
🏢 Current Account  
💼 Salary Account  
💳 Loan Account  

🛠️ Technologies Used

☕ Java  
💻 Core Java  
🧩 Object Oriented Programming
